# Body Explorer Game

An interactive, autism-accessible POV game for children aged 9-13 about puberty awareness.

## Features

- **Game-first experience** - No menus, no text-heavy UI, just exploration
- **Minimal text** - Almost no reading required
- **Large interactive zones** - Easy to tap/click
- **Calm interactions** - No timers, penalties, or sudden animations
- **Audio toggle** - Soft, predictable sounds with easy mute
- **6 micro-activities:**
  - 😊 Feelings - Explore emotions and breathing
  - 💧 Hygiene - Learn about sweat and deodorant
  - 📏 Growth - See body changes through stages
  - 🍎 Food - Understand nutrition and energy
  - 😴 Sleep - Experience rest and rejuvenation
  - 🛡️ Confidence - Build self-acceptance

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Accessibility

- Large hit targets for easy interaction
- Reduced motion safe
- ARIA labels for screen readers
- No flashing animations
- Predictable, calm interactions
- Works on tablets and desktops

## Design Philosophy

"Look → Touch → Something Happens"

This game is designed for children who cannot read well and need zero instructions to play.
